# BladePath — generated visual pack 01

The generated art pack is distributed separately as `BladePath_Visual_Pack_01.zip` (binary image upload is not available through the connected GitHub text-file integration).

To install, copy the zip's `Assets/Resources/UI/pack01/` directory into the Unity project's `Assets/Resources/UI/pack01/`. This is a normal Unity Resources folder. Do not include the zip itself in Assets.

MapScreen now uses these files automatically when present:
- `event_0.jpg`: ronin event
- `event_1.jpg`: monk event
- `event_2.jpg`: bandit event
- `event_3.jpg`: fox event
- `monk.jpg`: shrine/monk panel
- `herbalist.jpg`: herbalist panel

If a generated file is missing, the original UI texture remains in use. The zip also contains optional portraits, items, locations and VFX crops for later manual atlas work. Crops are conceptual and need art review before release.

**Important:** Until the binary images are copied into the Unity repository, the APK will continue to show the original art, not the new images.
