ЖУРНАЛ РАЗРАБОТКИ «ПУТЬ КЛИНКА» (BladePath) — для продолжения с любого аккаунта
================================================================================
Обновляется после каждого шага. Новые записи — в разделе «ХРОНОЛОГИЯ» (внизу, свежие сверху раздела).

1. ПРОЕКТ
---------
- Мобильная игра на Unity (Android), дуэли на мечах + карта похода (как «Герои 3»): область → места → бой.
- Репозиторий: github.com/l0g0ut-cmd-hub/L0g0ut-game (ПУБЛИЧНЫЙ — не делать закрытым: у закрытого лимит
  GitHub Actions 2000 мин/мес, а сборки по 15–25 мин).
- Рабочая ветка: bladepath-development. APK собирается при force-push в ветку apk-build
  (workflow «Build Android APK», ~15–25 мин; новая отправка отменяет ожидающую в очереди).
  Готовый APK: артефакт запуска и ветка apk-latest. Ссылка на запуск: https://github.com/l0g0ut-cmd-hub/L0g0ut-game/actions
- Игра некоммерческая, только для себя (лицензии ассетов — свободные, авторы указаны в THIRD_PARTY_SOUNDS.md).

2. ПРАВИЛА ВЛАДЕЛЬЦА (соблюдать всегда)
--------------------------------------
- Промты для ChatGPT (картинки/атласы): полностью готовые, в блоке кода; над каждым промтом подписывать, какой реф;
  всё в одном промте; рефы давать файлами (не архивом).
- Названия коммитов и сборок — по-русски.
- Главное меню не трогать (исключения, разрешённые владельцем: переключатель тумана войны; эффекты/звуки на
  экранах выбора путника и сложности — раскладку, кнопки, надписи не менять).
- Не удалять старые запуски Actions. Не платить за ассеты (только бесплатные).
- Тесты не гонять — сразу в сборку (validate_*.py — быстрые проверки кода, их запускать).
- «Цикад моих не трогай» — синтезированные цикады и сверчки остаются как есть.
- Никаких «пердящих» звуков: синтезированные голоса врагов, рык, низкий «вжух», «хлюп» — убраны, не возвращать.
- Анимации/эффекты — качественные, не «по 4 кадра»: брать ВСЕ кадры исходного видео (25 к/с), соседние кадры плавно смешивать.
- Если владелец просит перенести что-то в меню разработчика — убирать с основного экрана; не влезает — ужимать
  кнопки/шрифт, колонки или прокрутка.

3. ПОРЯДОК КОММИТА И СБОРКИ
---------------------------
  cd <клон репо>
  for f in tools/validate_*.py; do python3 -I $f; done      # validate_runtime_shots.py всегда FAIL (нет скриншотов) — это норма
  rm -rf tools/__pycache__
  git -c user.name="Claude" -c user.email="noreply@anthropic.com" commit -am "<по-русски>"
  git push -q origin HEAD:bladepath-development
  git push -q -f origin HEAD:apk-build                     # запускает сборку APK
  Если сборка упала с «Segmentation fault» (IL2CPP на CI иногда) — gh run rerun <id> --failed.
  Красный шаг «Publish scrubbed log to ci-logs branch» при зелёном «Build APK» — APK собран, это не страшно.
  Журналы сборок: ветка ci-logs, папка logs/run-<номер>.log (там отчёт о размерах ассетов — видно, попал ли файл в сборку).

4. СКАЧИВАНИЕ АССЕТОВ ЧЕРЕЗ GITHUB ACTIONS
------------------------------------------
- Песочница ассистента выходит в сеть только на GitHub/реестры пакетов, поэтому сайты качаются руками GitHub:
  ветка fx-fetch, файл .github/workflows/fx-fetch.yml (запуск — push в fx-fetch) → результат в ветку fx-out.
- CGHEVEN (cgheven.com, CC0): у бесплатных страниц в HTML есть contentUrl https://cdn.cgheven.com/file/...1K_ProRess4444.mov;
  PRO-страницы дают NONE. Видео → кадры ffmpeg (fps=25, все кадры) → листы собираются локально Python'ом
  (прозрачность из яркости). Бесплатно взять удалось: всплески энергии, ударная волна, щит, ауры, костёр, туман.
  Платные (PRO): дым из труб, пар, стелющийся туман, деревянный огонь, искры (cannon-spark на деле дымные клубы).

5. ВАЖНЫЕ ФАЙЛЫ (Assets/_Project/Scripts)
-----------------------------------------
- Game/Campaign.cs — данные похода, места (NodeType), дороги (LinkByRoads/Adjacent по нарисованным дорогам), охота, додзё…
- Game/MapScreen.cs — вся карта (IMGUI, виртуальная высота 540): окна мест, события, маршруты, домики (DrawBuildings,
  PlaceBuildings — расстановка без наложения), огонь/дым/свет (MapFire, MapSmoke, WarmLight), меню разработчика (DrawDev),
  уведомления (SetToast, Wrap/Typeset — перенос строк без висячих слов).
- Game/DayCycle.cs — время суток карты: утро/день/вечер/ночь, каждые 2 шага пути; фильтр, медальон UI/map_daytime,
  LightK (окна и фонари: утро/день 0, вечер 0,85, ночь 1,6; огонь — всегда). Режим (меню разработчика): по пути /
  утро / день / вечер / ночь / всегда день. Бой — во времени суток карты (Weather.MapTime → DayCycle.FightTime).
- Game/Weather.cs — погода боя; Weather.NoRain — выключатель дождя и грозы (и тучи с карты, MapClouds.SkyAt → 0).
- Game/UiFx.cs — эффекты и звуки интерфейса: листы UI/fx_ui_* (сложение света через Legacy Shaders/Particles/Additive),
  вспышка нажатых кнопок (VisualIdentity.KitButton), звуки ui_* , EquipSound по ячейке.
- Menu/MainMenuController.cs — экраны выбора путника/сложности (DrawPickFx, Picked).
- Game/InventoryScreen.cs — снаряжение, кузнец, торговец (DrawEquipFx — отклик надевания).
- Game/Juice.cs — звуки и эффекты боя (сэмплы Resources/Audio + синтез), FxSprite-эффекты CGHEVEN.
- Game/Music.cs — кото на карте (синтез), сямисэн в бою (Resources/Audio/music_battle.ogg), тайко.
- Game/SoundSettings.cs — звук вкл/выкл и что звучит (игра/музыка/оба); кнопки — в меню разработчика (карта и бой).
- Input/PrototypeInput.cs — кнопки боя и паузы; меню разработчика боя — 3 колонки × 6.
- Editor/IllustrationImport.cs — импорт без растяжения до степени двойки (place_*, event_>=12, fx_ui_*, fx_campfire,
  fx_mist, map_daytime) и потоковая музыка/подложки.
- tools/fx/cgheven/README.md — какие эффекты откуда; THIRD_PARTY_SOUNDS.md — авторы звуков/музыки/эффектов.
